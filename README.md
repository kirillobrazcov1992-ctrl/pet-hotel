# 🐾 Отель «Милый Дом» — передержка животных

Маленький сайт с сервером: главная, заявки на размещение (видны всем, телефон скрыт), живые отзывы (летящая лента), секретный кабинет модератора.

## Запуск локально
```bash
npm install
npm start          # http://localhost:3002
```

## Выкладка на Render (render.com)
1. Залейте проект в GitHub-репозиторий (файлы: `server.cjs`, `index.html`, `zayavka.html`, `comments.html`, `moder.html`, `style.css`, `img/`, `package.json`, `render.yaml`).
2. На Render: **New → Web Service** → подключите репозиторий.
3. Build: `npm install` · Start: `node server.cjs`
4. Готово! URL: `https://pet-hotel-vwab.onrender.com`

## Кабинет модератора
Секретная страница (нигде в меню не светится): `https://pet-hotel-vwab.onrender.com/moder.html`
- Пароль по умолчанию: `MilyDom2026!` — **обязательно смените!**
- Как сменить: Render → ваш сервис → **Environment** → добавьте переменную `ADMIN_PASSWORD` → Deploy.
- Быстрый вход по секретной ссылке: `https://pet-hotel-vwab.onrender.com/moder.html?p=MilyDom2026%21`
- В кабинете: видны телефоны заявок, можно удалять заявки и отзывы.

## Приватность телефонов
В публичных заявках номер телефона скрыт от всех посетителей (маскируется на сервере).
Полный номер видят только модератор в кабинете. Кристина связывается с клиентом сама.

> Данные (заявки и отзывы) хранятся в `pet-hotel.db` (SQLite). На бесплатном тарифе Render диск временный — при пересоздании сервиса данные сбросятся. Чтобы хранить постоянно — добавьте Persistent Disk и настройте путь к БД.
